# KnowME Knowledge

Agent-first, local-first personal knowledge OS for Huawei Mate60 / HarmonyOS: personal knowledge and growing memory, calendar and todo, with voice/text Agent interaction and direct visual control.

Codex Harness is the initial harness; MiniMax is the initial cloud provider. Both remain replaceable through product-owned adapter boundaries. Local inference is preferred when measured device capability permits; no silent provider fallback.
