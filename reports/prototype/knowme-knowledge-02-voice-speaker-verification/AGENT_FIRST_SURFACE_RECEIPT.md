# AGENT FIRST SURFACE RECEIPT — GOAL-KK-02 Contract R3 (PX-KK02-04)

## 设计

首屏即灵犀 Agent 对话界面，语音是 Agent 的附加捕获通道，不是录音机应用：

1. 头部：「灵犀 · KnowME 语音原型」+ 知识计数 + "0.1 原型 · 确定性演示(无真实 LLM)"诚实标注。
2. Agent 开场白（"我是灵犀。语音是你的新捕获通道:先说,我看清是谁说的、说了什么,再由你决定要不要入库。"）+ 对话区。
3. 常驻手动文本行（文本来源，不冒充语音）。
4. 已保存的知识列表（来源 chip + 时间 + 点击展开详情）。
5. 其下才是「语音捕获(附加能力)」区（点开始说话/点停止 + TEST_FIXTURE 演示入口）。
6. 机主声纹区（注册档案/本次验证两行独立）。
7. 技术诊断（引擎/模型详情）默认折叠。

动词全部为用户意图动词："点开始说话 / 点停止"（无"按住说话"等误导）。

## 实证

- LE run2：le-01（首屏布局完整，语音捕获为下方附加区）、le-06（冷开后对话上下文返回）。
- ED 本人：ed2-01（首屏）、ed2-05（上下文返回）、ed2-14（条目点击展开来源详情）。

## 结论

Agent-first 首屏与 Agent context return 在 final exact SHA 上双通道实证成立。本原型 Agent 为确定性演示壳（无真实 LLM/Harness/RAG），该边界已在首屏明示。
