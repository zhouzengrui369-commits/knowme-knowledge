灵犀 KnowMe · Agent First

Agent First，不是给应用加一个聊天框。

灵犀 KnowMe 从 Agent 出发：先理解目标和上下文，再组织知识、记忆、工具与行动，并让实践结果进入长期记忆，成为下一次行动的上下文。

什么是 Agent First？

传统软件通常从页面、按钮和功能模块开始；很多 AI 产品则是在既有软件上增加一个聊天入口。灵犀 KnowMe 探索的方向不同：Agent 先理解你要完成什么，再调用合适的知识、记忆、工具与工作面。

Agent First · Local First · Human Always

灵犀的 Agent-First 闭环

语音 / 文件 / 笔记 / 设备 → 感知与进入 → 长期记忆 + 知识图谱 → Agent 工作台 → 日程 / 任务 / 健康 / 工具 → 行动与结果 → 回到记忆。

重点不是功能数量，而是让输入、理解、行动和沉淀形成连续闭环。

六个当前重点场景

Neural Perception / 神经感知：降低语音与信息捕获成本。

Intelligent Agent Dialogue / 智能对话：在知识上下文中与 Agent 协作。

2D Knowledge Graph / 2D 知识图谱：理解主题、记录、来源之间的关系。

3D Cognitive Galaxy / 3D 认知星海：探索空间化的知识与认知网络。

Calendar & Tasks / 日程与任务：让知识进入真实计划与行动。

Health Context / 健康上下文：探索健康资料、节律和行动计划进入同一上下文。

为什么强调 Human Always？

Agent 可以增强人的理解、记忆和执行，但关键判断、确认与授权仍属于人。灵犀同时强调来源、上下文和重要行动尽可能可追溯、可检查。

当前状态边界

灵犀 KnowMe 仍在持续研发。公开网页、演示画面、代码存在、工程候选、产品体验通过、Human Owner Acceptance 与正式 Release 是不同状态；部分展示使用合成演示资料，不能把演示直接视为已经正式发布的产品能力。
